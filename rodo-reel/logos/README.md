# Logos

Add official logo files here and render again. A logo that is missing is drawn as text instead.

| File | Used in |
| --- | --- |
| `rodo.png` | End card, in place of the RODO wordmark (a transparent background works best) |
| `apollo.png` | Brand scene |
| `bridgestone.png` | Brand scene |
| `yokohama.png` | Brand scene |
| `jk-tyre.png` | Brand scene |

Brand logos are fitted inside a white panel. Use files at least 800 px wide so they stay sharp.
